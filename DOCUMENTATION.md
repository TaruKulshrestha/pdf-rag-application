# 1. Project Overview

## Purpose

The PDF Semantic Search Application enables users to upload PDF documents and search through them using natural language queries.

Unlike traditional keyword search, the application performs semantic search using vector embeddings generated by a transformer model. The embeddings are indexed using FAISS, allowing efficient similarity searches across document content.

---

# 2. Features

- Upload PDF documents
- Extract text from PDFs
- Generate semantic embeddings
- Store embeddings using FAISS
- Perform natural language search
- Retrieve contextually relevant content
- FastAPI backend
- Browser-based user interface

# 19. Deployment Notes

This application has been developed and tested locally.

Recommended deployment platforms

- Render
- Railway
- Google Cloud Run
- Azure App Service

Deployment considerations

- Ensure compatible Python version.
- Install all dependencies from `requirements.txt`.
- Configure a start command such as:

```bash
uvicorn app.main:app --host 0.0.0.0 --port $PORT
```

- Persist the FAISS index if the hosting platform uses ephemeral storage.
